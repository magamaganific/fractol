# Description
In this project I learned how to use a graphics library for the first time. The goal was to learn how to draw fractals and apply that knowledge to a window. Thus creating beautiful images via the mathematical formulas of Mandelbrot and Julia. All in all a very enjoyable project.

# AI usage
I used ChatGpt to familiarize myself with the different functions I'd have to use in the project as well as a way to correct some of my failed attempts. I also used it to understand the inner workings of the formulas and how I could express them properly through code.
